# Breach Protocol Game

A browser-based implementation of the Breach Protocol hacking minigame inspired by cyberpunk-themed games.

## Features

- Interactive code matrix with hex values
- Buffer with 7 slots represented by dotted boxes
- Visual progress bar that changes color as time decreases
- Game ends when time runs out or buffer is full
- Clear indication of matched sequences
- Game over screen with restart functionality

## How to Play

1. Click on cells in the code matrix to add them to your buffer
2. Each selection must be in the same row or column as the previous selection
3. Try to match the required sequences shown below the buffer
4. Game ends when the timer runs out or when your buffer is full
5. Your goal is to match as many sequences as possible
